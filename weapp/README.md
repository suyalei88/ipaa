# 零跑车控 · 小程序版

第三方、无广告、纯功能。只操作**你自己的车**、用**你自己的账号**。

这是 iOS 版（`ios/LeapmotorLite`）的小程序移植版，**首版做核心链路**：
登录 → 车况 → 车控 → 定位 → 设置/诊断。

---

## 一、先看这条硬约束（决定了整个架构）

微信小程序的 `wx.request` **只能**请求「在小程序后台配置过、且已 ICP 备案」的 HTTPS 域名，
而且加白名单时要**验证域名所有权**。

`appgateway.leapmotor.com` 是零跑的域名 —— 你既没法给它备案，也没法向微信证明你拥有它。
**所以小程序直连零跑在体验版/正式版必然失败**（只有开发者工具勾「不校验合法域名」
和手机「预览 + 打开调试」能绕过，预览码 25 分钟就失效）。

解决办法：**走微信云开发的云函数**。

```
   小程序  ──wx.cloud.callFunction──►  云函数 lmProxy  ──HTTPS──►  appgateway.leapmotor.com
  （你的手机）                          （腾讯云服务端）                （零跑）
                                         ↑
                            云函数发起的是普通 HTTPS 请求，
                            **不受小程序域名白名单限制**，
                            所以不需要备案域名、不需要买服务器。
```

签名与加密**全部留在云函数里**，小程序端不接触 `signKey`。云函数**完全无状态** ——
不保存你的账号、密码或 token 到任何数据库；会话由小程序端保存在本机，
每次调用时带上。

## 三、注册小程序 AppID（约 15 分钟）

1. 打开 <https://mp.weixin.qq.com/> → 右上角 **立即注册** → 选 **小程序**。
2. 填一个**从未注册过公众号/小程序**的邮箱 + 密码 → 去邮箱点激活链接。
3. 选主体类型 **个人**，填身份证号、手机号，用微信扫码做实名核身。
4. 注册完成后登录后台 → **设置 → 基本设置**，找到 **AppID**（`wx` 开头 18 位）。
   把它记下来，第 5 步要用。

> 个人主体**不能**用微信支付、部分类目受限，但**开发 + 体验版完全够用**。

---

## 四、用微信开发者工具打开项目

1. 下载安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。
2. **导入项目**：
   - 目录选这个仓库里的 **`weapp/`**（注意是 `weapp/`，不是仓库根目录）
   - AppID 填第 3 步拿到的那个
   - 后端服务选 **不使用云服务**（云开发在下一步单独开通，选哪个都会让你再开一次）
3. 导入后，工具会自动按 `project.config.json` 识别：
   - `miniprogramRoot` = `miniprogram/`
   - `cloudfunctionRoot` = `cloudfunctions/`

> `project.config.json` 里的 `appid` 是占位符 `wx0000000000000000`。
> 导入时工具会让你改；也可以手动把它替换成你的 AppID。
> 你自己的 AppID / 环境 ID 建议写在 **`project.private.config.json`**（已 gitignore），
> 别提交到公开仓库。

## 五、开通云开发

1. 开发者工具顶部点 **云开发** 按钮 → 按引导开通（个人主体可开通，有免费额度）。
2. 开通后会有一个 **环境 ID**，形如 `leapmotor-3g9xxxxxxxxxxxx`。
3. 打开 `miniprogram/config.js`：
   - 如果你**只有一个环境**，`cloudEnv` 留空即可（会用默认环境）。
   - 如果有多个环境，把环境 ID 填进 `cloudEnv`。

## 六、部署云函数

在开发者工具左侧文件树里：

1. 展开 `cloudfunctions/` → 右键 **`lmProxy`** → **上传并部署：云端安装依赖（不上传 node_modules）**。
   > 这个云函数**零 npm 依赖**（只用 node 内置 `crypto` / `https`），所以部署很快。
2. 部署完成后，在 **云开发控制台 → 云函数 → lmProxy → 配置** 里，
   把 **超时时间改成 20 秒**（默认 3 秒不够：车况和车控请求可能跑更久）。
3. 验证：云开发控制台 → 云函数 → lmProxy → **测试**，传
   ```json
   { "action": "ping" }
   ```
   应返回 `{"ok":true,"data":{"build":"weapp-1.0.0","actions":13}}`。

## 九、自测

云函数自带对拍测试，**不需要真实账号、不发任何网络请求**：

```bash
cd weapp/cloudfunctions/lmProxy
npm test
```

会跑两组：

- `test/vectors.js`（25 项）—— 签名 / 密钥派生 / oppwd / RSA / 严格 URL 编码 / 命令表，
  全部与 Python 参考实现 `client/leapmotor_client.py` 的测试向量逐条比对。
- `test/smoke.js`（8 项）—— 云函数路由、未登录拦截、未知 action、参数校验。

当前结果：**33 通过 / 0 失败**。

## 十、常见报错排查

| 现象 | 原因 / 处理 |
|---|---|
| `cloud function not found` / `errCode -501000` | 云函数没部署，或名字对不上（`config.js` 的 `cloudFunctionName` 必须是 `lmProxy`） |
| `errCode -601002` / `env not exists` | 云开发没开通，或 `config.js` 里的 `cloudEnv` 填错 |
| `request:fail url not in domain list` | 说明你在**直连**零跑域名 —— 检查是不是绕过了 `utils/api.js` 自己写了 `wx.request` |
| 云函数返回 `1019 参数不能为空` | 手机号 RSA 密文里的 `+` 被服务端按 form 规则解成了空格。本项目的 `encodeStrict` 已处理；如果你改过 URL 拼接逻辑，注意别用 `encodeURIComponent` 的默认行为 |
| 云函数返回 `302002002 签名信息校验失败` | 签名模式用错：**登录前**用 SHA256（无密钥）、**登录后**用 HMAC-SHA256（signKey）。见 `lib/sign.js` |
| `errCode -604100` | 云函数超时。去云开发控制台把 `lmProxy` 的超时改成 20 秒 |
| 车控提示「密码错误」但密码是对的 | 操作密码是 6 位数字，且**每个会话的 oppwd 密文都不同**（key/iv 来自 accessToken）。如果刚重新登录过，重新输入一次即可 |
| 登录后 2 小时全部接口失效 | 检查 `refreshToken` 是否存在（设置页会显示）。有的话会自动续期；没有就只能重新登录 |

## 十一、已知边界（诚实清单）

**已做**
- 短信验证码登录（RSA 加密手机号 → 外层 token → 换 JWT）
- refreshToken 滑动续期（TTL 7 天，自动在过期前续）
- 车况：电量 / 两套续航 / 门锁 / 后备箱 / 四窗 / 空调 / 车内温度 / 电池温度 /
  充电电流·电压·功率 / 总里程 / 采集时间
- 车控：门锁、鸣笛寻车、后备箱、前备箱、车窗（关/微开/半开）、空调开关、哨兵模式
- 定位：地图打点、坐标系假设切换、复制坐标、跳系统地图导航、算距我多远
- 诊断：全部 signalMap、未验证 payload 手动下发、cmdid 161 只读探测

**没做（有意或暂时做不到）**
- **蓝牙钥匙（BLE）** —— 小程序有 BLE API，但要复刻 CCC 数字钥匙协议（配对、证书、
  挑战响应），工作量是另一个量级，首版不做。
- **3D 看车** —— 需要引入 three.js 与离线车模包，首版不做。
- **充电中心（可写）** —— 预约充电 / 健康充电 / 充电上限，首版只读展示充电状态。
- **反查地址** —— 走官方 `/v3/geocode/regeo`，但这个端点**只有路径、没有抓包样本**，
  参数形状是猜的，属于探测性功能，不保证能用。失败时会把你试过的每种参数和原始响应
  都显示出来。
- **定位不是实时的** —— 这是**车端行为**，不是客户端 bug：车端下发的 `2190/2191`
  是车机存下来的一份位置，可以长时间完全不变。所以定位页显示的是
  **「这个坐标值多久没变过」**，而不是整包车况的采集时间（那个永远是「刚刚」）。
- **坐标系未知** —— 车端坐标属于 WGS-84 还是 GCJ-02 **没有证据能定**，
  两种假设差约 574 米。所以做成设置项让你站到车旁自己选，而不是替你猜。

## 十二、安全说明

- 云函数**不保存任何凭据**。会话（accessToken / refreshToken / signKey）由小程序端
  存在本机 `wx.setStorageSync` 里，每次调用时带上。
- 操作密码默认保存在本机，可在「设置 → 车控操作密码」里关掉「记住」，改成每次手输。
- 车控请求里的 `oppwd` 密文**每个会话都不同**（key/iv 来自 accessToken 前 64 字符），
  由云函数现场派生，小程序端不接触。
- 想更安全的话，可以把会话改成存云开发数据库、按 `openid` 取，
  这样连小程序端都不持有 token。当前版本为了「零依赖、无状态」没这么做。
- 只应操作**你自己的车**、用**你自己的账号**。
